# Portfolio Project Instructions

## Project Purpose

This project is a personal portfolio website rebuilt from an existing Framer portfolio.

The goal is to create a premium, modern, accessible, and high-performing portfolio that improves the original user experience.

---

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion animations

---

## Development Principles

- Build reusable components.
- Keep code clean and maintainable.
- Use semantic HTML.
- Prioritize accessibility.
- Use mobile-first responsive design.
- Avoid unnecessary dependencies.
- Do not modify unrelated files.

---

## Design Goals

The portfolio should feel:

- Premium
- Minimal
- Professional
- Fast
- Easy to navigate

Design inspiration:

- Apple
- Linear
- Vercel
- Stripe

Prioritize:

- Typography
- Spacing
- Visual hierarchy
- Clear user journeys
- Subtle animations

---

## UX Principles

Design decisions should follow Nielsen's 10 Usability Heuristics:

1. Visibility of system status
2. Match between system and real world
3. User control and freedom
4. Consistency and standards
5. Error prevention
6. Recognition rather than recall
7. Flexibility and efficiency of use
8. Aesthetic and minimalist design
9. Error recovery
10. Help and documentation

---

## Accessibility Requirements

Always consider:

- WCAG AA standards
- Keyboard navigation
- Screen reader support
- Color contrast
- Reduced motion preferences
- Semantic HTML

---

## Performance Goals

Optimize for:

- Fast loading
- Good Core Web Vitals
- Optimized images
- Minimal unnecessary JavaScript
- Efficient animations

---

## Workflow Rules

Before making changes:

1. Read relevant documentation.
2. Understand existing code.
3. Explain major changes briefly.
4. Only modify files required for the task.

The goal is not to copy the original Framer website exactly. The goal is to create a better user experience while preserving the original identity.

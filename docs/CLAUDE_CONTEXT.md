## Core Goals

The portfolio should:

- Communicate Emma's role quickly.
- Highlight UX/product thinking.
- Make case studies easy to evaluate.
- Show research, process, iteration, and outcomes.
- Encourage recruiter contact.

---

## Design Direction

Preserve:

- Warm ivory background
- Deep navy typography
- Editorial layouts
- Playful collage elements
- Human personality

Improve:

- Information hierarchy
- Case study scanning
- Accessibility
- Performance
- Maintainability

---

## Technical Rules

- Use Next.js App Router.
- Use TypeScript.
- Use reusable components.
- Prefer server components.
- Minimize client-side JavaScript.
- Follow accessibility requirements.
- Respect prefers-reduced-motion.
- Do not introduce unnecessary dependencies.

---

## Important Constraints

Do not:
- Replace the design personality with a generic portfolio template.
- Optimize only for visuals; prioritize UX communication.
- Build one-off components when reusable patterns exist.
- Make large changes without explaining why.
